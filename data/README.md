# Data access

This project uses the Upworthy Research Archive rather than generated campaign data.

1. Open the official archive: https://osf.io/jd64p/
2. Download `upworthy-archive-exploratory-packages-03.12.2020.csv`.
3. Save it in this directory.
4. Review the current archive guidance at https://upworthy.natematias.com/about-the-archive.html before making confirmatory claims.

The dataset is licensed CC BY 4.0. It is intentionally not duplicated in this repository.
